# 강우·지형 정보를 활용한 산사태 발생 기록 분석

발생 시점과 위치의 해상도가 낮은 산사태 기록을 활용하여 강우·경사·토지피복 변수의 상대적 중요도를 분석한다. 이를 통해 **강우 임계값을 산정할 때 고려할 변수와 누적 강우기간을 탐색**하는 것이 목적이다. 모델의 분류 성능과 SHAP 기여도를 함께 확인하며, 본 결과만으로 새로운 강우 임계값이나 산사태 발생 원인을 확정하지 않는다.

이 폴더는 가공된 입력부터 모델 학습, 고정된 TEST 평가까지 재현하는 실험 패키지다. 원 산사태 자료 정제와 원 DEM에서의 TerraMind 특징 추출은 앞선 데이터 구축 과정에 해당하며, 여기서는 제공된 표와 특징 캐시를 읽는다.

## 빠른 실행

저장소 루트에서 다음 명령을 실행한다. Python 가상환경과 Jupyter 커널은 같은 환경을 사용한다.

```bash
python -m pip install -r experiments/model_comparison/requirements.txt
cd experiments/model_comparison
python training.py --model xgboost --case ABC
```

개별 노트북을 사용할 경우 `notebooks/`의 원하는 파일을 열고 위 환경의 커널을 선택하여 처음부터 실행한다. 각 노트북은 입력 파일과 공통 코드에서 시작하며, 다른 노트북의 실행 상태에 의존하지 않는다.

입력 또는 저장 위치를 바꾸려면 `--data-dir`, `--output-root`, `--log-root`를 사용한다. 기본 분석 결과는 저장소 루트의 `output/model_comparison/<model>/<case>/`, 실행·QC·오류 로그는 `log/model_comparison/<model>/<case>/`로 분리된다. 자세한 인자는 `python training.py --help`에서 확인한다.

## 비교 모델

| 노트북 | 최종 분류기 입력 | 구성 |
| --- | ---: | --- |
| [01_xgboost.ipynb](notebooks/01_xgboost.ipynb) | 26개 | 기본 변수 → XGBoost |
| [02_catboost.ipynb](notebooks/02_catboost.ipynb) | 26개 | 기본 변수 → CatBoost |
| [03_terramind4_rf.ipynb](notebooks/03_terramind4_rf.ipynb) | 30개 | 기본 26 + 압축 DEM 특징 4 → Random Forest |
| [04_terramind16_rf.ipynb](notebooks/04_terramind16_rf.ipynb) | 42개 | 기본 26 + 압축 DEM 특징 16 → Random Forest |
| [05_terramind384_rf.ipynb](notebooks/05_terramind384_rf.ipynb) | 410개 | 기본 26 + TerraMind DEM 특징 384 → Random Forest |

최대시우량은 다섯 모델의 입력에서 제외한다. 따라서 마지막 구성은 **26 + 384 = 410변수**이며, 최대시우량 1개를 포함했던 과거 411변수 실험과 구분한다. 독립 MLP 분류기는 비교 목록에 포함하지 않는다.

TerraMind는 사전학습된 인코더를 고정하여 DEM의 공간 특징을 추출하는 데 사용했다. 사용 모델은 [TerraMind-1.0-small](https://huggingface.co/ibm-esa-geospatial/TerraMind-1.0-small/tree/960f7549bfe9d7a08946860042f83badd604c779), 고정 리비전은 `960f7549bfe9d7a08946860042f83badd604c779`이다. 이 패키지는 저장된 행정구역별 384차원 캐시를 사용하므로 실행할 때 TerraMind 본체를 새로 학습하거나 원 DEM 전체를 다시 추론하지 않는다.

4·16차원 구성에는 별도 보조 신경망이 있다. DEM 384차원을 `384 → 32 → 4` 또는 `384 → 32 → 16`으로 압축하고, 기본 26개 변수와 결합한 분류 헤드로 TRAIN에서 감독학습한다. VALID의 이진 교차엔트로피가 가장 작은 epoch를 선택한 뒤, 압축 인코더를 고정하고 TRAIN의 `26 + 압축 특징`으로 RF를 학습한다. 최종 TEST 분류기는 RF이며 TerraMind 본체의 가중치는 변경하지 않는다. PyTorch는 이 보조 압축 과정에 사용한다.

## A·B·C 표본의 의미와 구축 과정

원 산사태 목록은 산림청 및 한국도로공사 자료를 통합한 2021–2025년 5,160건이다. 위치를 확인할 수 있는 법정리 또는 읍·면·동에 연결하고, 강우·경사·토지피복 자료의 확보 상태를 검토하였다.

AWS·ASOS 시간 강우에서 1 mm 이상인 시간을 강우 시간으로 구분하고, 1 mm 미만인 시간이 12시간 연속되거나 자료 미확보가 12시간 연속되는 구간을 이벤트 분리 기준으로 사용하였다. 자료 미확보는 관측된 1 mm 미만 강우와 구분한다. 발생 시각이 기록된 산사태는 해당 시각에 연결되는 이벤트를 선택했다. 발생 기간만 기록된 경우에는 그 기간의 행정구역 평균 융합강우에서 최대 시간강우가 나타난 시각을 이용하여 대표 이벤트를 추정했다. 여러 이벤트에 걸친 동률 등으로 하나를 결정할 수 없는 기록은 미확정으로 남겼다.

| 유형 | 구성 | 라벨 |
| --- | --- | ---: |
| **A — 발생 기록 표본** | 산사태 발생 기록이 연결된 행정구역·대표 강우 이벤트. 같은 구역·이벤트의 기록은 집계한다. | 1 |
| **B — 시간 대조 표본** | A와 같은 행정구역·관측소에서 선택한 다른 강우 이벤트. | 0 |
| **C — 공간 대조 표본** | A의 강우 이벤트 시간대와 기준 종료일을 유지하면서 선택한 다른 행정구역. | 0 |

B는 A와 이벤트·종료일이 다르고, 알려진 발생 기록과 겹치지 않는 후보에서 추출했다. 같은 관측소에 연결된 기존 산사태 후보 이벤트와 B의 이벤트 또는 15일 누적강우 창이 겹치는 경우도 제외했다. C는 알려진 산사태 발생 기간·관련 강우 이벤트와 겹치는 구역을 제외하고 관측소 위치 이력과 공간자료 확보 상태를 확인했다. 상위 읍·면·동과 하위 리의 발생 기록도 함께 고려했다. C의 관측소가 A와 반드시 달라야 하는 것은 아니다.

A·B·C 각 하나를 `TRIPLET_ID`로 연결하여 1:1:1 묶음을 구성했다. 재연결된 A의 키를 기준으로 기존 B·C를 연결하고, 융합격자 또는 공간 특징의 품질을 확보할 수 없었던 일부 C는 같은 A 시간대를 유지하여 다시 선택했다. 최종 1,612묶음, 4,836행이며 A에는 원 산사태 3,994건이 집계되어 있다.

**B·C의 라벨 0은 ‘발생 기록이 포착되지 않음’이다. 실제 산사태가 없었다는 확정 라벨은 아니다.** A 연결 시 사용한 최대 시간강우 추정 규칙은 표본 구축 절차이며, 이번 모델에서 최대시우량을 입력 변수로 사용하는 것과 구분한다.

## 입력 데이터와 분할

- 기본 26변수: 1–15일 누적 융합강우 15개, 평균 경사·경사 임계값별 면적 비율 4개, 토지피복 대분류별 면적 비율 7개.
- [data/processed/samples.xlsx](data/processed/samples.xlsx): `Samples` 시트에 원 4,836행의 표본키, 라벨, 분할, 기본 변수와 품질 상태를 보존한다.
- [data/processed/dem_embeddings.parquet](data/processed/dem_embeddings.parquet): `SPATIAL_UNIT_ID`로 연결하는 행정구역별 TerraMind DEM 384특징.
- [data/processed/manifest.json](data/processed/manifest.json): 변수 목록과 재현에 필요한 데이터 구성·검증 정보.
- 열의 뜻과 자료 해석은 [DATA.md](DATA.md)를 참조한다.

공간자료 검토가 필요한 2묶음은 HOLD로 남겼다. 나머지는 TRAIN 966묶음, VALID 322묶음, TEST 322묶음으로 배정했다. 같은 A·B·C 묶음과 같은 행정구역의 15일 특징 창이 겹치는 표본은 같은 세트에 배정한다. 시드는 `20261030`이며, 묶음 수와 유형별 기준연도 분포를 고려하여 분할했다. 다른 행정구역의 같은 강우 이벤트는 서로 다른 세트에 포함될 수 있다.

다섯 모델의 TEST 비교에는 기존 공통 비교 기준을 적용한다. DEM 특징 확보가 불완전한 부귀리 1묶음을 제외한 **321묶음, 963행**이며 `COMMON_TEST_INCLUDED`로 표시한다. 원래 TEST 분할과 HOLD·REVIEW 상태는 바꾸지 않는다. TRAIN과 VALID는 원래의 2,898행·966행을 사용한다. 전처리와 모델 가중치는 TRAIN에서 학습하고 TEST를 모델 선택이나 threshold 조정에 사용하지 않는다.

## 성능과 변수 중요도

모델별 실행 결과는 [reports/metrics.csv](reports/metrics.csv)에 정리한다. AP를 주 비교 지표로 보고 ROC-AUC, Accuracy, Precision, Recall, F1을 함께 확인한다. Accuracy 등의 판정 기준은 기존 `0.5`를 유지하며 VALID와 TEST 결과를 나누어 읽는다. 표본별 예측값과 SHAP 관련 산출물은 모델별 결과 폴더에 저장한다.

SHAP는 모델이 예측 점수를 만드는 데 사용한 변수의 기여를 설명한다. 높은 중요도가 곧 실제 발생 원인이나 특정 누적일수의 독립적 효과를 뜻하지 않는다. 누적 강우 변수 사이에는 상관성이 크므로 중요도와 강우 임계값의 관계를 추가 검증해야 한다. 압축 DEM 코드는 학습된 잠재 특징이며 고도나 경사처럼 이름을 붙일 수 있는 물리량이 아니다.

## 해석 범위

1. 누적 강우량은 이벤트 종료일 전체를 포함하므로 실제 발생 이후의 강우가 포함될 수 있다. 사건 단위의 발생 기록 분류이며 실시간 사전 예측 검증은 아니다.
2. 대조 표본을 추출하여 A:B:C가 1:1:1이다. 양성 비율 1/3은 실제 전체 지역의 산사태 발생률이 아니며, 예측 점수를 실제 발생 확률로 바로 사용할 수 없다.
3. 다른 행정구역의 공유 격자와 같은 강우 이벤트가 세트 사이에 남을 수 있다. 새로운 지역·미래 강우사건에 대한 독립 일반화는 검증하지 않았다.
4. 토지피복 촬영 시점·경계 기준연도 등 원자료의 불확실성을 유지한다. 수치 QC 통과가 모든 연구 가정의 검증 완료를 뜻하지 않는다.
5. TEST는 이미 여러 차례 확인한 자료를 재사용한 탐색 비교다. 작은 점수 차이의 통계적 유의성은 검증하지 않았다.

## 자료 출처와 이용 조건

강우는 [기상청 API 허브](https://apihub.kma.go.kr/)와 [기상자료개방포털](https://data.kma.go.kr/), 토지피복은 [환경공간정보서비스](https://egis.me.go.kr/) 자료를 바탕으로 가공했다. 산사태 목록의 자료 제공기관, DEM·경계 및 캐시의 구체적인 범위는 [DATA.md](DATA.md)에 정리한다. 원 산사태 master, 원주소·좌표, 원 DEM, 개인 로컬 경로와 API 인증정보는 이 실험 패키지에 포함하지 않는다.

각 원자료와 TerraMind 모델의 이용 조건은 원 제공처를 따른다. 저장소의 코드와 제공 데이터의 권리를 구분하며, 원자료 재배포 권한이나 별도 데이터 라이선스를 이 문서에서 부여하지 않는다.
