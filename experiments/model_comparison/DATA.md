# 데이터 설명

이 문서는 `data/processed/`의 가공 입력을 설명한다. 원 산사태 자료, 원 강우 NetCDF, DEM 래스터와 토지피복 원본을 다시 수집하는 매뉴얼은 아니다. 모델 학습·평가에서 사용한 표본과 분할, 특징 캐시를 재현하기 위한 배포 범위다.

## 제공 파일

| 파일 | 내용 | 연결 기준 |
| --- | --- | --- |
| `samples.xlsx` | `Samples` 시트의 표본키·유형·라벨·원분할·기본26변수·품질 상태와 열별 단위·역할·설명을 담은 변수 사전 시트 | 한 행은 하나의 A/B/C 표본 |
| `dem_embeddings.parquet` | 행정구역별 TerraMind DEM 384차원 특징 캐시 | `SPATIAL_UNIT_ID`, 다대일 연결 |
| `manifest.json` | 변수 순서·파일 구성 및 검증 정보 | `files`의 파일명→SHA-256과 특징 목록을 실행 코드가 확인 |

`samples.xlsx`의 `Samples` 시트는 원 1,612묶음, 4,836행과 메타데이터 12개·기본 변수 26개, 총 38열을 제공한다. HOLD 또는 공통 TEST에서 제외되는 행을 삭제한 축약 데이터가 아니다. 최대시우량, 원 산사태 master의 상세 주소·좌표·비고·개인 로컬 경로와 원사건 연결표는 학습 재현에 필요한 입력에서 제외한다. 숫자형 특징은 숫자로 저장하며 소수점 이하 6자리 화면 표시는 저장값을 6자리로 반올림한다는 뜻이 아니다.

## 표본 메타데이터

| 열 | 뜻 | 모델 입력 여부 |
| --- | --- | --- |
| `AUDIT_SAMPLE_KEY` | 묶음 ID와 A/B/C를 결합한 표본키. 표본별 예측·검증 연결에 사용 | 제외 |
| `TRIPLET_ID` | A 한 개와 대응 B·C를 연결하는 묶음 ID | 제외 |
| `SAMPLE_CLASS` | A 발생 기록, B 시간 대조, C 공간 대조 | 제외 |
| `TARGET_EVENT_RECORDED` | A=1, B/C=0. 0은 발생 기록 미포착을 뜻함 | 타깃 |
| `SPATIAL_UNIT_ID` | 법정리 또는 읍·면·동 분석 구역의 식별키 | 캐시 연결용, 입력 제외 |
| `SPLIT` | 원 TRAIN·VALID·TEST·HOLD 배정 | 행 선택용 |
| `COMMON_TEST_INCLUDED` | 공통 TEST 321묶음에 포함되는 행의 표시 | TEST 행 선택용 |
| `INPUT_NUMERIC_QC` | 숫자형 입력의 결측·범위 등 기존 QC 상태 | 검증용 |
| `HOLD_REASON` | 보류 사유가 있는 경우의 원 기록 | 검증용 |
| `TRAINING_READY` | 앞선 데이터 구축 단계의 연구 검토 상태 | 검증용 |
| `LANDCOVER_TEMPORAL_STATUS` | 토지피복 촬영시점 등 시점 적합성의 검토 상태 | 검증용 |
| `LANDCOVER_NAME_REVIEW` | 토지피복 원본 분류 명칭의 검토 표시 | 검증용 |

구체적으로 배포되는 메타데이터 열은 `manifest.json`과 엑셀 헤더를 따른다. 메타데이터·식별자·분할·검토 플래그를 특징 목록에 자동 포함하지 않는다. `TRAINING_READY=False` 또는 REVIEW를 임의로 True/PASS로 바꾸지 않는다. 기존 실험에서 허용한 표본 범위와 검토 상태를 함께 보존한 것이다.

## 기본 입력 26개

### 누적 강우 15개

| 열 | 단위 | 정의 |
| --- | --- | --- |
| `FUSION_01D_MM`–`FUSION_15D_MM` | mm | 이벤트 기준 종료일을 포함하여 이전 1–15개 달력일의 융합 시간강우량을 누적한 값 |

시간대는 KST다. 15일 창은 `END_DATE - 14일 00:00`부터 `END_DATE + 1일 00:00` 직전까지다. 여기서 `END_DATE`는 데이터 구축 당시 사용한 이벤트 기준 종료일의 개념이며 배포 엑셀의 메타데이터 열은 아니다. 이벤트 시작·종료시각과 특징 창의 시작·종료시각 열도 배포본에는 포함하지 않는다. 이러한 달력일 단위 집계에서 `FUSION_02D_MM`은 발생 시각 직전의 정확한 48시간 강우와 항상 같지는 않다. 각 값은 격자에 포함된 단위 보정 원 NetCDF의 60분 강우로 계산했으며, 결측을 0으로 채워 완전한 강우량처럼 취급하지 않았다.

강우 이벤트 구분에는 AWS·ASOS 관측을 사용했다. 모델 입력인 `FUSION_*`는 해당 관측소의 강우량을 그대로 복사한 열이 아니라, 행정구역에 연결한 500 m 융합기상 격자의 평균 시간강우에서 계산한 파생 변수다. 최대시우량 열 `FUSION_EVENT_MAX_1H_MM`은 이번 배포 모델의 특징 목록에 없다.

### 경사 4개

| 열 | 단위 | 정의 |
| --- | --- | --- |
| `SLOPE_MEAN_SLOPE_DEG` | 도(°) | 행정구역의 유효 DEM 기반 경사 평균 |
| `SLOPE_GE_20DEG_FRACTION` | 0–1 비율 | 유효 경사 면적 중 20° 이상 면적의 비율 |
| `SLOPE_GE_30DEG_FRACTION` | 0–1 비율 | 유효 경사 면적 중 30° 이상 면적의 비율 |
| `SLOPE_GE_40DEG_FRACTION` | 0–1 비율 | 유효 경사 면적 중 40° 이상 면적의 비율 |

경사는 높이 단위가 m로 확인된 5 m DEM에서 Horn 3×3 방법으로 계산했다. 경계 픽셀은 픽셀 중심 기준이며, 경사를 계산하는 3×3 이웃은 모두 유효해야 한다. 경사 면적 비율의 분모는 유효 경사 면적이다.

### 토지피복 7개

| 열 | 대분류 | 단위·분모 |
| --- | --- | --- |
| `LANDCOVER_L1_100_FRACTION_ADMIN` | 시가화·건조지역 | 행정구역 면적 대비 비율 |
| `LANDCOVER_L1_200_FRACTION_ADMIN` | 농업지역 | 같음 |
| `LANDCOVER_L1_300_FRACTION_ADMIN` | 산림지역 | 같음 |
| `LANDCOVER_L1_400_FRACTION_ADMIN` | 초지 | 같음 |
| `LANDCOVER_L1_500_FRACTION_ADMIN` | 습지 | 같음 |
| `LANDCOVER_L1_600_FRACTION_ADMIN` | 나지 | 같음 |
| `LANDCOVER_L1_700_FRACTION_ADMIN` | 수역 | 같음 |

비율은 0–1 단위이며 백분율 0–100과 구분한다. 각 표본의 이벤트 기준연도에 해당하는 피복 자료를 연결했다. 해당 연도 자료가 실제 산사태 이전에 촬영되었다는 의미는 아니다. 피복 촬영 시점의 REVIEW는 유지한다.

## TerraMind 특징 캐시와 압축

캐시는 `SPATIAL_UNIT_ID`와 `TM_DEM_000`–`TM_DEM_383`을 포함한다. 384개 열은 사전학습 인코더가 DEM의 공간 패턴에서 계산한 잠재 특징이며, 각각의 열을 고도·경사·피복 비율처럼 직접 해석할 수 없다. 정규화된 입력과 네트워크 변환에서 나온 값이므로 음수도 유효한 특징값일 수 있다. 표준편차나 부호를 물리 단위로 해석하지 않는다.

사용한 사전학습 모델과 리비전:

- [ibm-esa-geospatial/TerraMind-1.0-small](https://huggingface.co/ibm-esa-geospatial/TerraMind-1.0-small/tree/960f7549bfe9d7a08946860042f83badd604c779)
- `960f7549bfe9d7a08946860042f83badd604c779`

기존 DEM 특징 추출은 5 m 자료를 10 m로 집계하고, 224×224 입력을 고정 인코더에 넣어 얻은 196개 위치별 384특징을 행정구역 단위로 집계하는 방식이다. 이 배포 패키지는 그 결과 캐시에서 시작한다. 원 DEM 추론 전체의 재실행은 포함하지 않는다. 토지피복과 강우는 이번 TerraMind 인코더의 모달리티 입력이 아니라 기본 표형 변수로 결합한다.

4·16차원 구성은 TerraMind 자체의 출력 차원을 바꾸는 모델이 아니다. 저장된 DEM384를 별도 보조 신경망으로 `384 → 32 → 4/16`으로 압축하고, 기본26변수와 중간 결합하여 TRAIN 라벨로 학습한다. VALID BCE로 epoch를 선택하고 인코더를 고정한 뒤 RF를 학습한다. 이 과정의 표준화 평균·표준편차도 TRAIN에서만 계산한다. 최종 RF 입력은 각각 30개와 42개이며, 압축하지 않은 RF 입력은 410개다.

압축 코드의 번호는 모델·학습 실행에 종속된다. 4차원 코드00과16차원 코드00을 같은 의미로 비교하지 않는다. 보조 신경망의 ReLU 출력이 모든 표본에서 0인 차원이 있다면 이는 비활성 학습 특징일 수 있으며, 원 DEM의 관측 결측과 구분한다.

## 분할·QC와 공통 TEST

| 구분 | 원 묶음 수 | 원 행 수 | 실행에서의 처리 |
| --- | ---: | ---: | --- |
| TRAIN | 966 | 2,898 | 전처리·모델 가중치 학습 |
| VALID | 322 | 966 | 압축 모델의 epoch 선택 및 검증 |
| TEST | 322 | 966 | 기존 분할 보존. 공통 비교에는 321묶음·963행 사용 |
| HOLD | 2 | 6 | 학습·성능평가 제외, 원 사유 보존 |

같은 묶음의 A/B/C는 같은 세트에 배정한다. 같은 행정구역에서 360시간 특징 창이 겹치는 묶음도 같은 세트에 둔다. 다른 지역의 같은 강우 이벤트나 같은 STN 자체는 분할 그룹 제약으로 사용하지 않았다. 연도별 균형을 고려한 60/20/20 분할이지 미래 연도 전체를 분리한 시간 외삽 평가가 아니다.

HOLD 2묶음은 B 표본의 원 토지피복 분류 간 공간 중첩 때문이다. 비율 합계를 임의로 1로 정규화하거나 검토 상태를 통과로 고치지 않았다.

춘천 북산면 부귀리(`RI_5111038023`)는 TEST의 한 묶음(`ARG_2b34a4b9f5e863642186`)에 해당하며 DEM 특징을 만들 때 약 9.82% 영역을 확보하지 못했다. 새 값으로 대체하지 않고 해당 묶음 A/B/C 전체를 공통 비교에서 제외했다. `SPLIT=TEST` 원값을 보존하고 `COMMON_TEST_INCLUDED=False`로 구분한다. 공통 TEST는 A·B·C 각각 321행, 총 963행이다.

앞선 DEM 검토에서 중복된 경계 조각을 제거한 파생 경계와 장봉리의 승인된 소면적 집계영역 제외를 반영한 특징 캐시를 사용했다. 원 경계나 DEM 자체를 수정하여 결측이 없어진 것으로 표시한 것이 아니다. 원형상·격자 확보율, 피복 촬영 시점 및 경계 시점의 불확실성을 함께 고려해야 한다.

## 예측과 SHAP 해석

`P_EVENT_RECORDED`는 구성된 표본에서 발생 기록 라벨을 구분하는 모델 점수다. 표본 추출에 따라 양성 비율이 1/3이므로 실제 전체 지역의 산사태 발생 확률과 동일시하지 않는다. 판정 기준은 기존 0.5를 유지하며 TEST에서 최적화하지 않는다.

SHAP 기여도는 선택한 모델, 설명 대상 표본, 배경 분포와 출력 단위에 종속된다. 누적 강우 열은 서로 상관되어 있으므로 ‘2일 누적강우 중요도가 높음’을 2일 강우만이 원인이라는 결론이나 최적 경보 임계기간의 확정으로 해석하지 않는다. `TM_DEM_*`와 압축 DEM 코드의 기여도는 잠재 특징에 대한 설명이다. 기여도가 높아도 특정 능선·사면 위치가 중요했다는 공간 귀속 결과를 직접 제공하지 않는다.

## 재현 정보

`reports/provenance.json`의 `reference_execution`은 수치 결과를 생성한 원 실행의 설정과 fingerprint를 보존한다. `release_files`는 현재 배포 파일의 해시이며, `relocation_validation`은 경로 정리 후 수행한 입력·동일 모델 예측·노트북 설정·CLI 검증이다. 경로 정리를 새 모델 학습 결과로 표시하지 않는다.
