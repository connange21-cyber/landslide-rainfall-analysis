선택한 STN의 시간당 강우량 분포

현재 표시 구간을 전체 A/B 이벤트에 적용. 유형별 같은 관측 시간을 중복 제거하며 결측은 제외합니다.

B는 발생 기록이 포착되지 않은 비교표본이며 실제 미발생 확정은 아닙니다. A는 산사태 기록과 겹치는 강우 후보입니다.

강우는 현재 RAIN_DATAS의 AWS 우선·ASOS 보완값이며 관측소 위치 이력을 적용했습니다. 결측과 다른 위치의 관측은 0mm로 채우지 않았습니다.

기존 A/B 이벤트 구간을 표시합니다. 누적 15일 화면에는 이벤트가 끝난 뒤 같은 날짜의 나머지 시간도 포함될 수 있습니다. 모든 시각은 KST이며 막대는 [시작, 종료) 1시간 구간입니다.

B 이벤트와 이전 15일 창은 같은 STN의 알려진 산사태 연결 후보 이벤트와 겹치지 않도록 추출했습니다. 학습·평가용 분리는 아직 수행하지 않았습니다.
